## Map, not flow

These are discrete maps. Each new point comes only from the last one — no Euler step, no `dt`. Start at the seed, iterate, and the pile of points is the attractor. Classical Chaos draws that orbit as a growing line trail (same transport contract as Lorenz and Aizawa).

## Type A — three knobs

The smallest of the set. Archive defaults `a=1.586`, `b=1.124`, `c=0.281`, seed `(0,0,0)`:

<BlockMath math={'x_{n+1} = a + y_n - z_n y_n'} />
<BlockMath math={'y_{n+1} = b + z_n - x_n z_n'} />
<BlockMath math={'z_{n+1} = c + x_n - y_n x_n'} />

```ts
const next = polynomialTypeATick(x, y, z, a, b, c)
```

## Type B — six knobs

Same cyclic coupling, but each product term gets its own scale. Archive `index.js` sits near `a=1.6691`, `b=1.0405`, `c=0.2818`, `d=0.2818`, `e=0`, `f=1.1055`. A second preset keeps the README decimals.

<BlockMath math={'x_{n+1} = a + y_n - z_n (b y_n)'} />
<BlockMath math={'y_{n+1} = c + z_n - x_n (d z_n)'} />
<BlockMath math={'z_{n+1} = e + x_n - y_n (f x_n)'} />

## ABS — absolute values

Each new coordinate is a linear mix of `x,y,z` and `|x|,|y|,|z|`. Seven coefficients per axis (`xa`…`zg`). The default preset matches the archive’s main script; a second preset comes from the alternate workshop file.

<BlockMath math={'x_{n+1} = a_x + b_x x + c_x y + d_x z + e_x |x| + f_x |y| + g_x |z|'} />

(and the same shape for `y` and `z` with their own coeffs)

## Type C — quadratic per axis

Six coefficients per axis (`xa`…`zf`). Each update is a quadratic in the current and next cyclic partner:

<BlockMath math={'x_{n+1} = a_x + x(b_x + c_x x + d_x y) + y(e_x + f_x y)'} />

with the same pattern cycling through `y` and `z`.
