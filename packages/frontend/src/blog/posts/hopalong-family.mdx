Barry Martin found the Hopalong map in 1981. People also call it the Skull attractor. Unlike Lorenz, there is no smooth trail of rates. You take a point `(x, y)`, run a short formula, get the next point, and pile those points into a cloud.

I like it because the rule is tiny and the cloud still surprises me. Change one term and the whole field reorganizes. Below are the five versions Classical Chaos ships, all live at once so I stop relying on memory.

Five live clouds. Pause any card if you want quiet. Open full on a card when you want that variant’s knobs — this page is for looking, not tuning.

## Map, not flow

Each new point comes only from the last one. No integrating along a curve. Start near a seed, keep iterating, and the silhouette that piles up is the attractor.

Classic Hopalong and Attractor 1 turn knobs labeled `a`, `b`, `c`. The positive / additive / sinusoidal trio use the same three knobs on a shared outer shape. Either way: many steps from a seed, then a colored cloud.

## Classic

Defaults on the classic stage sit near `a = 1.4`, `b ≈ 5.16`, `c ≈ 2.74`, seed `(0.03, 0.01)`. Color walks through hue as the points accumulate so the cloud doesn’t go flat.

Martin’s classic form:

<BlockMath math={'x\\prime = y - \\mathrm{sgn}(x)\\,\\sqrt{|b x - c|}'} />
<BlockMath math={'y\\prime = a - x'} />

```ts
const nextX = y - Math.sign(x) * Math.sqrt(Math.abs(b * x - c))
const nextY = a - x
x = nextX
y = nextY
```

On the full classic stage you can shove those knobs around (including a wild preset near `a ≈ −11`) and the cloud rebuilds from the seed. Open full on the Classic card when you want that.

## Attractor 1 (sin for sign)

Same two-line skeleton as classic, but the archive kept a typing mistake: `sin` where `sign` was meant, and the absolute value uses `|b x − 1 − c|`. Soft multiplier, still a Hopalong-shaped map:

<BlockMath math={'x\\prime = y - 1 - \\sin(x - 1)\\,\\sqrt{|b x - 1 - c|}'} />
<BlockMath math={'y\\prime = a - x - 1'} />

Defaults sit near `a ≈ 2.38`, `b = 5.2`, `c = 4.8`, seed `(0, 0)`. It is not the sinusoidal cousin below — that one swaps the whole outer recipe.

## Three cousins: one term changes

Positive, additive, and sinusoidal keep `y' = a − x` and only rewrite the x-step’s middle piece.

**Positive** flips the radical to addition, still signed:

<BlockMath math={'x\\prime = y + \\mathrm{sgn}(x)\\,\\sqrt{|b x - c|}'} />
<BlockMath math={'y\\prime = a - x'} />

**Additive** drops the sign: always add the square root.

<BlockMath math={'x\\prime = y + \\sqrt{|b x - c|}'} />
<BlockMath math={'y\\prime = a - x'} />

**Sinusoidal** swaps the radical for a sine:

<BlockMath math={'x\\prime = y + \\sin(b x - c)'} />
<BlockMath math={'y\\prime = a - x'} />

Because sine stays between −1 and 1, small `b` stays near-periodic (thin rings). The stage defaults sit nearer `a = 2.5`, `b = 4`, `c = 0.2` so the cloud fills; classic-style `b ≈ 5` also works.

So classic and Attractor 1 stand on the two-line Martin-style rule (sign vs sin). The other three only disagree about the middle x-step: signed sqrt, unsigned sqrt, or sine.
