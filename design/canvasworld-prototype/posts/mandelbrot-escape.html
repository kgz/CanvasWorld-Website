Escape time: how the Mandelbrot boundary gets drawn

Jun 2026 · 7 min read

Every pixel is a tiny experiment. Map screen coordinates to a complex plane, iterate z → z² + c, and count how long the orbit stays inside radius 2. The boundary is where that count refuses to settle.

The experiment

z₀ = 0
zₙ₊₁ = zₙ² + c
escape if |z| > 2

Points that never escape are painted as the set (here: near-void). Escapers get a color from their iteration count. Higher max-iter sharpens filaments; lower max-iter keeps the prototype responsive.

Why the boundary is interesting

Interior and far exterior are cheap. Near the edge, orbits linger — that is where most of the work (and the visual detail) lives. Zooming into seahorse valley multiplies that cost; production ports push the loop to GLSL.

This mini player deliberately caps iterations so the page stays interactive. The gallery Mandelbrot will trade CPU for fidelity once it ships as a full stage.
