Design notes

A HUD that doesn’t compete with the void

Jun 2026 · 4 min read

The live React app still ships drei’s <Stats /> — a green-on-black mrdoob box that fights our glass/teal chrome. The replacement is a quiet mono chip: same information, brand-aligned surface.

Rules that stuck

  • Secondary to wordmark, title, and transport — never a badge on the fractal.
  • --font-mono, muted / soft-accent ink, void glass + border.
  • Top-right stage inset, clear of the left params panel.
  • Hideable via .is-hidden or data-hide-fps for captures.

What we refused

No sparkline, no dual ms panel, no green histogram. One number and a unit — enough for a perf glance while the attractor keeps the stage. 

.fps-counter {
  font-family: var(--font-mono);
  color: var(--muted);
  /* void glass + border — tokens only */
}
